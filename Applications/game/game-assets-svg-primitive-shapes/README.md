# Game Assets Svg Shapes

- Depended on Lit3 Templates 

Game assets shapes are visual elements that can be used in the game to create various shapes and objects. These shapes can be used for both visual representation and collision detection. The assets include polygons, rectangles, and rockets, which can be loaded from SVG files or created programmatically.        

They should be distinct equal and have a unique id to be used in the game. They can be used in various game objects to create different visual effects and interactions.        

*They are*: 
- SVG and Purely visual elements 
- Have a set of points that are Vector2 @monorepo/core-math

*They are not*: 
- Game objects, they are used by game objects to create visual representation and collision detection.    

## Polygons
Polygons are defined as 2D figures formed by a closed polygonal chain of straight line segments. A closed polygon connects end-to-end (e.g., triangle, square), while an "open" polygon (more accurately called an open polygonal line) does not close at the ends. A true polygon must be closed to enclose a region.
