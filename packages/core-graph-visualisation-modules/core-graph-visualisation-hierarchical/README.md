
# Features 

## Scenarios 
### Scenario: 
- Given: a single node in a graph 
- When: a child node is addes to the graph
- Then: the child node should be rendered as a child of the parent and the child should have the same x position as the parent and a y position that is below the parent by a fixed amount 
### Scenario: New child node is addes to a graph
- Given: a graph with a root node and one child node
- When: a new child node is added to the graph  
- Then: the new child node should be rendered as a child of the root node and the new child should now be rendered to the left and 
right below the root node.
