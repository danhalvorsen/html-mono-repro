# What 

This is a download from [link](https://github.com/jgraph/drawio/blob/24468c3911ae9c9a43716c7b588514b48ebd0711/src/main/webapp/stencils/pid/feeders.xml) and it contains the geometric shapes for the PID feeders stencil. 

# Why   
I need to convert the XML file to SVG files so that I can train a AI model to recognize these shapes in the future.     

# How 
1. Draw.io have a library of stencils that can be used to create diagrams. The stencils are defined in XML files and can be imported into draw.io.  This project is a POC on how to convert the XML file to SVG files.
